# Plazio privacy

Static pages for the Plazio app (Krug-Digital), served by GitHub Pages from branch `main`, folder `/`. No build step, no GitHub Actions.

- `de.html` / `en.html`: privacy policy
- `impressum.html`: legal notice (must match the notice inside the app)
- `style.css`: shared styles

Publisher details (name, address, e-mail, phone) are the same as in the other Krug-Digital apps.
